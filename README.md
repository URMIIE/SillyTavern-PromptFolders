# 프롬프트 토글 그룹 (Prompt Folders)

실리태번 **프롬프트 관리자**(채팅 완성)의 토글을 접고 펼 수 있는 그룹(폴더)으로 묶어 주는 확장이에요.

## 기능

- **그룹 안에 그룹** — 자주 안 쓰는 건 접어 두고, 자주 쓰는 건 위에.
- **그룹 머리** — 켜진 개수(`3/7`), 그룹 전체 켜기/끄기, 마우스를 올리면 실제 위치·토큰 합계.
- **하나만 켜기(택1)** — 언어·시점처럼 하나만 골라야 하는 그룹은 머리의 「택1」을 누르면(⋮ 메뉴에도 있어요) 하나를 켤 때 나머지가 자동으로 꺼져요. 잘못 눌렀으면 알림의 「되돌리기」로 켜져 있던 토글까지 원래대로.
- **그룹 편집기 (한 창)** — 왼쪽에서 그룹을 고르고 오른쪽에서 토글을 여러 개 골라 한 번에 넣거나 빼요. 그룹 만들기 · 이름 고치기 · 그룹 안에 그룹(몇 단계든) · 택1 · 그룹 풀기까지 한 창에서. 검색, 「전체 / 고른 그룹 / 그룹 없음」 거르기, Shift+클릭 범위 · 끌어서 여러 개(휴대폰은 길게 누른 뒤 끌기). 도구 줄의 「그룹 편집」으로 열고, 그룹 하나만 고칠 땐 그 그룹 ⋮ 메뉴의 「이 그룹 편집」 — 같은 편집기가 그 그룹과 안의 그룹만 보이게 열려요.
- **자동으로 그룹 만들기** — 구분선 토글, 시작·끝 표시(⤵/⤴, `<tag>`/`</tag>`, start/end, 같은 장식으로 감싼 ★…★ · ╔…╗/╚…╝ 짝), 빈 이름 토글, 비슷한 이름끼리(띄어쓰기 없는 한자 이름도) 최대 2단(큰 그룹 → 작은 그룹)으로 묶어요. 결과는 그룹 편집기에 그대로 채워져서 이름을 고치고 토글을 옮긴 뒤 만들고, 마음에 안 들면 알림의 「되돌리기」.
- **그룹 없는 토글만** — 이미 그룹이 있으면 남은 토글을 먼저 기존 그룹에 넣어요(앞뒤 토글 · 비슷한 이름 · 같은 구역을 보고 뚜렷할 때만). 맞는 데가 없는 것만 새 그룹으로 묶어요. 이번에 들어가는 토글과 새 그룹엔 「new」(기존 그룹엔 「+n」)가 붙고, 「이번에 바뀐 것」으로 그것만 볼 수 있어요. 프리셋 새 버전에 그룹을 가져온 뒤 남은 토글을 정리할 때 좋아요.
- **AI로 다시 묶기** — 미리보기 창에서 AI가 다시 묶어 줘요. 연결은 지금 채팅 연결 · 실리태번 연결 프로필 · 공급자 직접(모델 선택) 중에서 골라요. 아래 「AI로 묶기 — 보내는 것」을 보세요.
- **끌어서 옮기기** — 토글이나 그룹 머리를 끌어서 옮기고, 그룹 머리 위에 놓으면 그 안으로. 휴대폰은 ☰ 손잡이나 그룹 ⋮ 메뉴의 위로/아래로.
- **그룹 배치** — 「그룹 순서 = 실제 위치」(옮기면 실제 프롬프트 위치도 바뀜) 또는 「보기만 그룹 순서」(실제 위치는 그대로).
- **색** — 기본은 그룹 이름 앞 이모지 색을 차분한 톤으로. 견본 10개나 직접 고르기, 표시 방식(점 / 색 띠 / 없음).
- **프리셋과 같이 다님** — 그룹이 프리셋 파일 안에도 저장돼서, 프리셋을 공유하면 그룹도 같이 가요.
- **가져오기/내보내기 · 다른 프리셋에서 가져오기** — 그룹만 JSON 파일로 주고받거나, 예전 버전 프리셋의 그룹을 새 버전으로 바로 가져와요. 토글은 같은 번호로, 없으면 같은 이름으로 찾고, 새로 생긴 토글은 앞뒤가 같은 그룹이면 그 안에 넣어요. 가져올 그룹은 그룹 편집기에 먼저 채워져서, 몇 개가 맞았는지와 토글마다 어떻게 맞췄는지(이름으로 맞춤 · 새 토글) 보고 고친 뒤 가져올 수 있어요.
- **보물상자(柏宝箱) 그룹 가져오기** — 프리셋 제작자가 보물상자로 그룹을 만들어 프리셋 파일에 넣어 둔 경우, ⋯ 메뉴에 「보물상자(柏宝箱) 그룹 가져오기」가 생겨요. 보물상자가 깔려 있지 않아도 돼요.
- **그룹 이름 한국어로** — 편집기에 한자 · 가나로 된 그룹 이름이 있으면 「그룹 이름 한국어로」 단추가 나와요. 기계 번역(구글 · Bing · Yandex, 실리태번에 키 · 주소를 넣어 뒀다면 DeepL · DeepLX · Lingva · LibreTranslate도) 또는 AI(지금 채팅 연결 · 연결 프로필 · 공급자 직접)로 고를 수 있고, 그룹 이름만 보내요. 번역한 뒤에도 「다시 번역」으로 다른 방법을 써 볼 수 있어요.
- **AI 지시문 묶음** — 확장 설정 「AI 지시문」에서 AI로 묶기 · 그룹 이름 번역 지시문을 고치고, 묶음으로 여러 개 저장해 골라 써요. 답 형식은 확장이 알아서 붙이고, 기본 지시문은 늘 남아 있어요.
- **테마·모바일 대응** — 쓰는 테마 색을 따르고, 좁은 화면과 터치에서도 돼요.

## 설치

실리태번 **확장 → 확장 설치**에 아래 주소를 붙여 넣어요.

```
https://github.com/URMIIE/SillyTavern-PromptFolders
```

실리태번 1.19.0 이상, 채팅 완성 API에서 작동해요.

## 사용법

1. **AI 응답 설정 → 프롬프트**(프롬프트 관리자)를 열어요.
2. 그룹이 하나도 없으면 도구 줄의 ✨(**자동으로 그룹 만들기**)나 **그룹 만들기**를 눌러요.
3. 그룹 머리의 **⋮** 메뉴: 그룹 편집, 안에 새 그룹, 색 바꾸기, 하나만 켜기, 위로/아래로 옮기기, 그룹 풀기.
4. 도구 줄: 그룹 편집, 원래 순서로 보기, 모두 접기/펼치기, **⋯**(자동 그룹·그룹 배치·그룹 색 표시·내보내기/가져오기·그룹 모두 풀기).

설정(확장 패널 → *프롬프트 토글 그룹*): 그룹 배치, 도구 줄 위치(자동 · 목록 위 · 「총 토큰」 줄 옆 · 다른 확장 줄과 나란히 · 목록 맨 밑 — 자동이면 다른 확장과 자리가 겹칠 때 비켜 가요), AI로 묶기 연결, 그룹 색 표시, 실제 위치 번호, 긴 이름 두 줄, 프리셋 파일에도 저장.

## AI로 묶기 — 보내는 것

「AI로 다시 묶기」는 누를 때만, 고른 연결로 한 번 요청해요.

- **보내는 것**: 토글 이름과 순서. 「그룹 없는 토글만」일 때는 기존 그룹 이름과 그룹마다 토글 이름 3개까지도 같이 보내요(기존 그룹에 넣을 수 있게).
- **보내지 않는 것**: 토글 안의 프롬프트 내용, 채팅 내용, 그 밖의 모든 것.
- **보내는 곳**: 직접 고른 연결(지금 채팅 연결 · 연결 프로필 · 공급자)뿐이에요. 확장 제작자나 다른 서버로는 아무것도 가지 않아요.

처음 누를 때 같은 안내가 뜨고, 「다시 묻지 않기」를 고르기 전까지 매번 물어봐요.

### 1.4.1 · 2026.11.07

- 채팅을 열 때 프롬프트 목록을 다시 그리는 동안 도구 줄 자리를 수십 번 다시 재느라 느려지던 것을, 한 화면에 한 번만 재게 해서 고쳤어요.

### 1.4 · 2026.11.06
- 프리셋 제작자가 다른 그룹 확장으로 프리셋 안에 넣어 둔 그룹을 ⋯ 메뉴에서 그대로 가져올 수 있어요. 그 확장이 깔려 있지 않아도 되고, 편집기에서 고친 뒤 가져와요.
- 한자 그룹 이름을 「그룹 이름 한국어로」로 한 번에 옮길 수 있어요. 번역기(Google · Bing · Yandex · DeepL)나 AI 중에 골라요.
- 확장 설정 「AI 지시문」에서 AI로 묶기 · 이름 번역 지시문을 고치고 묶음으로 여러 개 저장해 골라 쓸 수 있어요. 기본 지시문은 늘 그대로 남아요.
- 확장 설정 「도구 줄 위치」에서 목록 위 · 「총 토큰」 줄 옆 · 다른 확장 줄과 나란히 · 목록 맨 밑 중에 고를 수 있어요. 「자동」이면 다른 확장이 같은 자리를 차지할 때 알아서 비켜 가요.

### 1.3 · 2026.11.05
- 그룹 편집 입구가 도구 줄 · ⋯ 메뉴 · 그룹 ⋮ 세 군데로 나뉘어 헷갈리던 것을, 목록 위 ✎ 단추 하나로 모았어요. 그룹 ⋮ 의 「이 그룹 편집」은 그 그룹과 안의 그룹만 보이게 열려요.
- 그룹 전체를 켜고 끈 뒤 「되돌리기」가 목록을 통째로 다시 그려 느리던 것을, 켬 · 끔만 그 자리에서 되돌리게 해서 스위치를 다시 누르는 것만큼 빨라졌어요.
- AI로 다시 묶기가 토글의 켜짐 · 꺼짐 상태까지 보내던 것을, 이름과 순서만 보내게 바꿨어요.
- 휴대폰에서 편집 창 높이가 고정돼 목록이 저장 단추와 겹치던 것과, 기울인 제목 글꼴 때문에 창 제목 윗부분이 잘리던 것을 고쳤어요.

### 1.2 · 2026.11.02
- 그룹 편집기에서 토글 여러 개를 한 번에 골라 넣고 뺄 수 있고, 그룹 안에 그룹도 만들 수 있어요. 그룹 안 토글 순서는 끌어서 바꿔요.
- 다른 프리셋(예전 버전)에서 그룹을 가져올 수 있어요. 편집기에서 맞춘 결과를 보고 고친 뒤 가져와요.
- 그룹 머리의 「택1」을 눌러 그 그룹에서 하나만 켜지게 할 수 있어요.
- 그룹을 옮기거나 켜고 끄거나 풀거나 편집한 뒤 「되돌리기」로 원래대로 돌릴 수 있어요.
- 「그룹 없는 토글만」으로 자동 묶기를 하면 남은 토글로 새 그룹만 만들던 것을, 비슷한 기존 그룹에 먼저 넣고 맞는 곳이 없을 때만 새 그룹을 만들게 했어요. AI로 다시 묶기도 기존 그룹에 넣을 수 있고, 새로 묶인 토글에는 new, 늘어난 그룹에는 +n 이 붙어요.
- 토글을 누를 때마다 토큰을 다시 세고 목록 전체를 다시 그려 긴 채팅에서 1초 넘게 멈추던 것을, 누른 줄만 그 자리에서 바꾸고 토큰은 잠시 뒤 한 번만 세게 해서 누르는 즉시 바뀌게 했어요.
- 자동 그룹이 ★…★ · ╔╗ 같은 구분 표시를 못 알아보던 것과, 일부 프리셋에서 자동 그룹을 누르면 멈추던 것을 고쳤어요.
- 그룹을 열고 닫을 때마다 설정 전체를 저장해서 스크롤이 튀고 화면이 잠깐 멈추던 것을, 열고 닫기는 그 자리에서만 하게 해서 고쳤어요.
- 하위 그룹을 풀면 안의 토글이 그룹 밖으로 빠지던 것을, 위 그룹으로 옮겨 가게 고쳤어요.
- 그룹 머리와 단추 크기가 정해진 값이라 테마마다 프롬프트 줄과 어긋나거나 폰에서 커지던 것을, 테마의 프롬프트 줄 모양을 그대로 따르게 해서 고쳤어요.
- 프롬프트 줄을 강제로 보이게 하는 테마에서 토글이 두 번 보이던 것과, 편집기 저장 · 취소 단추가 창 밖으로 잘리던 것을 고쳤어요.
- 그룹 순서를 바꾸거나 지우면 다른 그룹 색까지 바뀌던 것을, 색이 그 그룹을 따라다니게 고쳤어요.
- 패널이 좁을 때 목록이 패널 밖으로 나가 위 단추들과 줄이 어긋나던 것을, 패널 안에 맞추게 고쳤어요.
