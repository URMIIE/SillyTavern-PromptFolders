# 프롬프트 그룹 (Prompt Folders)

실리태번 **프롬프트 관리자**(채팅 완성)의 토글을 접고 펼 수 있는 그룹(폴더)으로 묶어 주는 확장이에요.

## 기능

- **그룹 안에 그룹** — 자주 안 쓰는 건 접어 두고, 자주 쓰는 건 위에.
- **그룹 머리** — 켜진 개수(`3/7`), 그룹 전체 켜기/끄기, 마우스를 올리면 실제 위치·토큰 합계.
- **하나만 켜기(택1)** — 언어·시점처럼 하나만 골라야 하는 그룹은 ⋮ 메뉴에서 켜 두면, 하나를 켤 때 나머지가 자동으로 꺼져요.
- **그룹 편집기 (한 창)** — 왼쪽에서 그룹을 고르고 오른쪽에서 토글을 여러 개 골라 한 번에 넣거나 빼요. 그룹 만들기 · 이름 고치기 · 그룹 안에 그룹(몇 단계든) · 택1 · 그룹 풀기까지 한 창에서. 검색, 「전체 / 고른 그룹 / 그룹 없음」 거르기, Shift+클릭 범위 · 끌어서 여러 개(휴대폰은 길게 누른 뒤 끌기). ⋯ 메뉴의 「그룹 한꺼번에 편집」이나 그룹 ⋮ 메뉴의 「그룹 편집」으로 열어요.
- **자동으로 그룹 만들기** — 구분선 토글, 시작·끝 표시(⤵/⤴, `<tag>`/`</tag>`, start/end), 빈 이름 토글, 비슷한 이름끼리 최대 2단(큰 그룹 → 작은 그룹)으로 묶어요. 결과는 그룹 편집기에 그대로 채워져서 이름을 고치고 토글을 옮긴 뒤 만들고, 마음에 안 들면 알림의 「되돌리기」.
- **AI로 다시 묶기** — 미리보기 창에서 AI가 다시 묶어 줘요. 연결은 지금 채팅 연결 · 실리태번 연결 프로필 · 공급자 직접(모델 선택) 중에서 골라요. 아래 「AI로 묶기 — 보내는 것」을 보세요.
- **끌어서 옮기기** — 토글이나 그룹 머리를 끌어서 옮기고, 그룹 머리 위에 놓으면 그 안으로. 휴대폰은 ☰ 손잡이나 그룹 ⋮ 메뉴의 위로/아래로.
- **그룹 배치** — 「그룹 순서 = 실제 위치」(옮기면 실제 프롬프트 위치도 바뀜) 또는 「보기만 그룹 순서」(실제 위치는 그대로).
- **색** — 기본은 그룹 이름 앞 이모지 색을 차분한 톤으로. 견본 10개나 직접 고르기, 표시 방식(점 / 색 띠 / 없음).
- **프리셋과 같이 다님** — 그룹이 프리셋 파일 안에도 저장돼서, 프리셋을 공유하면 그룹도 같이 가요.
- **가져오기/내보내기 · 다른 프리셋에서 가져오기** — 그룹만 JSON 파일로 주고받거나, 예전 버전 프리셋의 그룹을 새 버전으로 바로 가져와요. 토글은 같은 번호로, 없으면 같은 이름으로 찾고, 새로 생긴 토글은 앞뒤가 같은 그룹이면 그 안에 넣어요. 바꾸기 전에 몇 개가 맞는지 먼저 보여 줘요.
- **테마·모바일 대응** — 쓰는 테마 색을 따르고, 좁은 화면과 터치에서도 돼요.

## 설치

실리태번 **확장 → 확장 설치**에 아래 주소를 붙여 넣어요.

```
https://github.com/URMIIE/SillyTavern-PromptFolders
```

실리태번 1.19.0 이상, 채팅 완성 API에서 작동해요.

## 사용법

1. **AI 응답 설정 → 프롬프트**(프롬프트 관리자)를 열어요.
2. 그룹이 하나도 없으면 도구 줄의 ✨(**자동으로 그룹 만들기**)나 **그룹 만들기**를 눌러요.
3. 그룹 머리의 **⋮** 메뉴: 그룹 편집, 안에 새 그룹, 색 바꾸기, 하나만 켜기, 위로/아래로 옮기기, 그룹 풀기.
4. 도구 줄: 그룹 만들기, 원래 순서로 보기, 모두 접기/펼치기, **⋯**(자동 그룹·그룹 한꺼번에 편집·그룹 배치·그룹 색 표시·내보내기/가져오기·그룹 모두 풀기).

설정(확장 패널 → *프롬프트 그룹*): 그룹 배치, AI로 묶기 연결, 그룹 색 표시, 실제 위치 번호, 긴 이름 두 줄, 프리셋 파일에도 저장.

## AI로 묶기 — 보내는 것

「AI로 다시 묶기」는 누를 때만, 고른 연결로 한 번 요청해요.

- **보내는 것**: 토글 이름, 순서, 켜짐/꺼짐.
- **보내지 않는 것**: 토글 안의 프롬프트 내용, 채팅 내용, 그 밖의 모든 것.
- **보내는 곳**: 직접 고른 연결(지금 채팅 연결 · 연결 프로필 · 공급자)뿐이에요. 확장 제작자나 다른 서버로는 아무것도 가지 않아요.

처음 누를 때 같은 안내가 뜨고, 「다시 묻지 않기」를 고르기 전까지 매번 물어봐요.
